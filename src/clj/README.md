# src/clj

Clojure source loaded at startup.

- `clojure/` -- GENERATED by `upstream/derive` from Rich Hickey's
  source at `clojure-1.12.6`, each class in clotran's name; see
  `clojure/GENERATED.md` and `upstream/clojure/src/clj/clojure/PROVENANCE.md`. Never
  edited -- edit the renaming and re-run it; if clotran cannot load one
  of these files, that is clotran's bug.
- `clotran/` -- clotran's own namespaces (`.cljf`), loaded when first
  named. Nothing of ours loads before core.clj (DEVIATIONS.md 2).

Layout mirrors upstream's `src/clj/clojure/...` (namespace segments as
directories) because that is the classpath convention `load` and
`require` resolve against.
