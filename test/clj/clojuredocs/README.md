# clojure.core as clojuredocs.org documents it

Every example, and every code block in the notes, on the clojure.core
pages of clojuredocs.org, run through `clj` and through clotran with the
values compared. The fourth scorecard, alongside our tests, the derived
language suite and libraries loading: code nobody here wrote, exercising
the corners people actually use.

- `examples.edn` -- the cases, GENERATED by `scripts/clojuredocs extract`
  from the site's data export
  (https://clojuredocs.org/clojuredocs-export.json, sha256
  `20f8a78aa6a7c2637eaa19a89ca784c48523563199aa0b0f4cf10a1b56ae75a9`,
  fetched 2026-09-27). Do not edit; re-extract. The examples are the
  clojuredocs community's, not ours.
- `expected/` -- what `clj` answered for each var's cases, GENERATED by
  `scripts/clojuredocs expect`. No expected value is typed by hand.

```
scripts/clojuredocs extract          # export -> examples.edn
scripts/clojuredocs expect [var ..]  # clj's answers -> expected/
scripts/clojuredocs run [var ..]     # clotran's answers, compared and scored
scripts/clojuredocs score            # score again from the saved answers
```

`run` writes each failing case -- its code, clj's lines, clotran's lines --
to `build/clojuredocs/REPORT.txt`.

## What a case is

One example: its text with REPL prompts and printed output removed, read
by the host's own reader (`{:read-cond :allow}`), each form evaluated in
order in a namespace of the case's own. Each form answers one line: its
value through the oracle's canon (maps and sets sorted, since hash order
is not the language; long seqs cut at 100), what it printed, or `!error`.
Object identity hashes are removed. A case agrees when every line does.

## Tags

- `:portable` -- the var is in the clojure.core/cljs.core intersection
  (scripts/derive-tests' rule) and the code names no Java class, static,
  method or constructor. The headline number.
- `:interop` -- names Java. Counted apart and not chased: matching the
  JVM's classes is not the goal.
- `:reader-cond` -- uses `#?`. clotran's feature is `:cljf` (DEVIATIONS
  33), so a `:clj`/`:cljs`-only conditional reads as nothing here; these
  are reported on their own line.
- `:nondet` -- rand, shuffle, gensym, time...: only whether a form throws
  is compared.
